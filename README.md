FILE HANDLING PROGRAM – TASK DESCRIPTION

The objective of this task is to write a C program that demonstrates file handling operations. The program performs basic file operations such as creating a file, writing data to a file, reading data from a file, and appending data to an existing file.

In this program, a text file is created or opened using standard C file handling functions. The user is allowed to enter data, which is written into the file. After writing, the program reads the stored data from the file and displays it on the screen. This helps to verify that the data has been saved correctly.

The program also supports appending new data to the file without removing the previously stored content. Proper error checking is included to ensure that the file is opened successfully before performing any operation.

This task helps students understand how files are handled in C programming and how data can be stored permanently. File handling is widely used in applications such as record management, data storage, and report generation. The program provides practical experience with real-time file operations in C.
